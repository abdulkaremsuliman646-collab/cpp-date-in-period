# C++ Date In Period

A C++ console application that determines whether a given date falls within a specified date period.

The project builds on date comparison and period structures to check whether a date is between a start date and an end date.

## Features

- Compare two dates
- Represent dates using structures
- Represent periods using nested structures
- Determine whether a date is before, equal to, or after another date
- Check whether a date falls within a given period
- Read dates and periods from user input

## Concepts Practiced

- C++ Structures
- Nested Structures
- Enumerations
- Functions
- Const References
- Boolean Logic
- Conditional Operators
- Date Comparison
- Problem Solving
- Code Organization
